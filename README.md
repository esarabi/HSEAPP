# دستیار HSE

وب‌اپلیکیشن پیش‌رونده (PWA) برای مدیریت کارهای روزانه کارشناس ایمنی، بهداشت و محیط زیست.
کاملاً آفلاین کار می‌کند، روی موبایل و دسکتاپ قابل نصب است و همه داده‌ها فقط روی دستگاه کاربر (IndexedDB) ذخیره می‌شود.

## امکانات

- **پیمان‌ها و حوزه‌ها** — هر کارشناس چند پیمان دارد؛ هر پیمان به یک حوزه (بوستان‌ها، خدمات شهری و…) تعلق دارد و کاتالوگ عدم انطباق همان حوزه در بازدید استفاده می‌شود
- **بازدید** — انتخاب پیمان، ثبت موقعیت GPS فعلی، عکس‌های قبل و بعد، انتخاب چند «شناسه عدم انطباق» با جستجو بر اساس شناسه یا عنوان (ارقام فارسی هم پشتیبانی می‌شود)، افزودن مورد جدید در لحظه که در کاتالوگ ذخیره می‌شود، توضیح هر مورد، پیگیری و ثبت رفع
- **کاتالوگ عدم انطباق** — چک‌لیست HSE نگهداشت فضای سبز (۲۲۱ شناسه 308-xxx با نوع سؤال، فرآیند/محل، شرح عدم انطباق، الزام قانونی، اقدام اصلاحی، امتیاز، درجه بحرانیت و مهلت رفع) به‌صورت داخلی؛ ورود کاتالوگ حوزه‌های دیگر از فایل xlsx یا CSV با نگاشت خودکار ستون‌ها
- **گزارش بازدیدها** — فیلتر پیمان و بازه زمانی، توزیع بر اساس درجه بحرانیت و فرآیند، پرتکرارترین عدم انطباق‌ها، تفکیک پیمان، خروجی CSV و چاپ/PDF؛ صفحه هر بازدید هم قابل چاپ است
- **بازرسی و چک‌لیست** — ۷ چک‌لیست آماده (عمومی، اطفای حریق، برق، ارتفاع و داربست، PPE، بهداشت، محیط زیست)، ثبت نتیجه هر آیتم و خروجی CSV
- **شرایط ناایمن** — ثبت مغایرت با عکس، شدت ریسک، مسئول رفع و مهلت؛ با انتخاب «نامطابق» در بازرسی به‌طور خودکار فرم ثبت باز می‌شود
- **حوادث و شبه‌حوادث** — فرم کامل گزارش حادثه، علت ریشه‌ای، اقدام اصلاحی و پیگیری وضعیت
- **مجوز کار (PTW)** — صدور مجوز کار گرم/سرد/ارتفاع/فضای بسته/حفاری/برق/بالابری با اقدامات احتیاطی پیش‌فرض و قابل ویرایش، شماره‌گذاری خودکار، هشدار انقضا
- **پرسنل و آموزش** — پرونده افراد، سوابق آموزشی با تاریخ انقضا، معاینات دوره‌ای و هشدار ۳۰ روز قبل از انقضا
- **وظایف و یادآوری** — وظایف تکرارشونده (روزانه تا سالانه) که با انجام هر نوبت، نوبت بعدی خودکار ساخته می‌شود
- **داشبورد** — خلاصه موارد باز، عقب‌افتاده و در حال انقضا
- **پشتیبان‌گیری** — خروجی/ورودی JSON شامل عکس‌ها برای انتقال بین دستگاه‌ها، خروجی CSV از هر ماژول
- رابط فارسی راست‌به‌چپ با تقویم شمسی، پوسته روشن/تیره، فونت وزیرمتن (به‌صورت آفلاین)

## فناوری

React 19 · TypeScript · Vite · [Dexie](https://dexie.org) (IndexedDB) · React Router · vite-plugin-pwa (Workbox)

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه نهایی:

```bash
npm run build
npm run preview
```

خروجی در پوشه `dist` یک سایت استاتیک است و روی هر هاست استاتیکی (GitHub Pages، Netlify، Vercel، nginx و…) قابل انتشار است. برای نصب به‌عنوان PWA، سایت باید روی HTTPS باشد.

### انتشار روی GitHub Pages

ورک‌فلو `.github/workflows/pages.yml` با هر push روی `main` برنامه را می‌سازد و منتشر می‌کند.
کافی است در تنظیمات ریپوزیتوری، بخش **Pages**، گزینه **Source** را روی **GitHub Actions** بگذارید.
اگر برنامه زیر یک مسیر فرعی منتشر می‌شود، متغیر `VITE_BASE` را هنگام build تنظیم کنید (ورک‌فلو این کار را خودکار انجام می‌دهد).

## ساختار پروژه

```
src/
  db/          مدل داده‌ها، اسکیما Dexie و بارگذاری کاتالوگ داخلی
  data/        چک‌لیست‌ها، اقدامات احتیاطی و کاتالوگ‌های عدم انطباق (catalogs/*.json)
  pages/       صفحه‌های هر ماژول
  components/  اجزای مشترک رابط کاربری
  utils/       تاریخ شمسی، خروجی/پشتیبان، فشرده‌سازی عکس
```

## افزودن کاتالوگ حوزه جدید

۱) از داخل برنامه: صفحه «عدم انطباق‌ها» ← انتخاب یا ساخت حوزه ← «ورود از Excel/CSV». فایل باید سطر عنوان با ستون‌های «شناسه» و «عنوان» داشته باشد؛ ستون‌های «نوع سؤال»، «فرآیند / محل»، «شرح عدم انطباق»، «الزام قانونی»، «اقدام کنترلی اصلاحی»، «امتیاز»، «درجه بحرانیت» و «مهلت رفع عدم انطباق» به‌طور خودکار شناسایی می‌شوند. فرمت قدیمی `.xls` پشتیبانی نمی‌شود؛ در اکسل با Save As به `.xlsx` تبدیل کنید.

۲) به‌صورت داخلی: یک فایل JSON با ساختار `src/data/catalogs/parks.json` بسازید و آن را به `src/data/catalogs/index.ts` اضافه کنید تا در همه نصب‌ها به‌طور خودکار بارگذاری شود.

## نکته درباره داده‌ها

داده‌ها فقط در مرورگر همین دستگاه نگهداری می‌شوند. پاک کردن داده‌های سایت در مرورگر، همه اطلاعات را حذف می‌کند؛ به‌صورت دوره‌ای از بخش **تنظیمات ← پشتیبان‌گیری** فایل پشتیبان بگیرید.
